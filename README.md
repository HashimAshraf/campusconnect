# CampusConnect

CampusConnect is a React frontend for discovering and managing university events.

## Run locally

```sh
npm install
npm run dev
```

Open the URL printed by Vite and use the **Student**, **Organizer**, or **Admin** buttons on the login page to try each role.

- Students can search events, register or cancel, and leave feedback for past events they attended.
- Organizers can publish events with posters, edit or remove their events, record attendance, and export attendee lists.
- Admins can approve organizers and remove users or events.

Demo accounts and changes are stored in the browser. Use sample credentials and sample data for this frontend deliverable. Poster uploads support JPEG, PNG, and WebP files up to 512 KB. Clearing this site's local storage resets the demo.

`npm run lint` checks the source. `npm run build` creates the production frontend.
